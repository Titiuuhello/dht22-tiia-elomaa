# dht22-tiia-elomaa
DHT22-anturi harjoitus
Ohjelma mittaa lämpötilaa ja ilmankosteutta 10 sekunnin välein. Jos mittaustulos muuttuu, ohjelma lähettää uuden arvon MQTT-palvelimelle. Näytöllä näkyvät mittaustulokset ja tieto siitä, lähetettiinkö uusi viesti.
WiFi-tunnukset ovat erillisessä wifi_config.py-tiedostossa, jota ei tietoturvasyistä ole ladattu GitHubiin.
